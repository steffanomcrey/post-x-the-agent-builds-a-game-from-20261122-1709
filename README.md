One prompt, one agent, one game. My AI agent built a tiny browser snake game
from a single prompt, played it, and filmed the whole loop: the prompt, the
agent working, the finished game running, ending with make.fun's referral end
card. The video is posted on X from @AlisonGrace0210; POST.json names the post.

The game itself is in this repo as game.html: open it in a browser, steer with
arrow keys or WASD, eat the red food, grow, get faster.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) validates POST.json and copies it to
`/output/POST.json`, where the gate reads it.

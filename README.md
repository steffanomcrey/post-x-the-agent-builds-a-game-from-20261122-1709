One prompt, one agent, one game. I gave my AI agent a single prompt and it
built a tiny browser snake game, played it, and filmed the whole loop: the
prompt appearing, the agent working in a terminal, the finished game running
with a climbing score, ending with make.fun's referral end card. The video is
posted on X from @AlisonGrace0210; POST.json names the post.

The game itself ships here as game.html: open it in a browser, steer with
arrow keys or WASD (Space starts, R restarts after game over), eat the red
food, grow, get faster.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) validates POST.json and copies it to
`/output/POST.json`, where the gate reads it. It also checks the copy back
byte-for-byte before reporting success.
